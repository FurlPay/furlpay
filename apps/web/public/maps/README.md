# Country geometry

countries-110m.json is derived from Natural Earth 1:110m admin-0 countries v5.1.2, public domain.
Source: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_110m_admin_0_countries.geojson
Coordinates rounded to three decimals; properties reduced to country code/name. Boundaries are cartographic context, not claims of jurisdiction. Map anchors use the existing Natural Earth centroid asset; they do not locate wallets.
