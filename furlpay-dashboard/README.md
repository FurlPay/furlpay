# FurlPay Merchant Dashboard

Next.js 15 App Router application for FurlPay merchants to manage payments, payouts, disputes, and analytics.

## Tech Stack
- Next.js 15 (App Router)
- React 19
- Tailwind CSS
- `@furlpay/js` SDK

## Getting Started

```bash
npm install
npm run dev
```

## Structure
- `/app` - Next.js routes
- `/components` - Reusable UI components
- `/lib` - Utilities and FurlPay client initialization
