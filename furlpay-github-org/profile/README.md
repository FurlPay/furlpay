# FurlPay — Open-Source Solana Payment Infrastructure

Welcome to FurlPay! We are building the fastest, cheapest, and most reliable open-source payment infrastructure on Solana.

## Repositories
- [furlpay-core](https://github.com/furlpay/furlpay-core) - The core Solana programs and payment execution engine.
- [furlpay-js](https://github.com/furlpay/furlpay-js) - TypeScript/JS SDK.
- [furlpay-python-sdk](https://github.com/furlpay/furlpay-python-sdk) - Python SDK for backend integration.
- [furlpay-dashboard](https://github.com/furlpay/furlpay-dashboard) - Next.js merchant dashboard.
- [furlpay-mobile-app](https://github.com/furlpay/furlpay-mobile-app) - React Native consumer app.
- [furlpay-brand](https://github.com/furlpay/furlpay-brand) - Brand assets and guidelines.

## Quick Start
Head over to [furlpay.com/docs](https://furlpay.com/docs) to get started.
