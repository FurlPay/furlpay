# Contributing to FurlPay

We love your input! We want to make contributing to FurlPay as easy and transparent as possible, whether it's:
- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new features

## Process
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints.
5. Issue that pull request!

## Commit Messages
We follow Conventional Commits (e.g. `feat: added new payment type`, `fix: resolving rounding error`).
