# Manual Outreach Templates

**Send these by hand, ≤15–20/day, each personalized.** No automation. The `[bracketed]` fields must be filled from the prospect's actual profile/activity — a generic send is worse than no send.

## Sequence
1. **Warm first** (Week 2): leave 1 genuine, insightful comment on their recent post. Not "great post" — add a fact or a real question.
2. **Connect** (Week 3): personalized note (≤300 chars) OR InMail for top targets who don't accept connects.
3. **Follow up** (Week 4): once, 4 days later, offering a low-friction next step (sandbox key / 15-min demo). Then stop.

## Week-4 follow-up (both segments)
> Hi [First name] — following up once. We're opening our developer sandbox next week. Want a sandbox API key to test it, no call required?

## Rules
- Personalize the first line with something only-them (post, launch, funding, role change).
- One follow-up max. Silence = a no; respect it.
- Track every send in `leads.csv`. If Segment A reply rate < Segment B after 20 sends each, shift remaining effort to the winner.
- InMail credits are refunded when a prospect replies within 90 days — personalization literally pays for itself.
