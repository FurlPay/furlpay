# iOS release readiness

**Status: NOT BUILDABLE FOR RELEASE.** No Apple Developer account exists; no signing, no provisioning, no App Store Connect record. Nothing below claims a signed or submitted build. (The separate SwiftUI Guardian app, `ios/FurlPayGuardian`, is out of scope here; this is the Expo app, `native-app/`.)

`native-app/ios/` is **gitignored and regenerated by `expo prebuild`**. The source of truth is `native-app/app.json` + `app.config.js` + `plugins/`; every fix below was made there, never in `ios/`.
