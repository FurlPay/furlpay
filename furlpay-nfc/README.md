# @furlpay/nfc

NFC tap-to-pay module for FurlPay on Solana. 

Provides Host Card Emulation (HCE) processing, NDEF record handling, and standard FurlPay NFC protocols for passing payment requests between terminals and mobile wallets.

## Installation

```bash
npm install @furlpay/nfc
```

## Usage

```ts
import { NfcPaymentEmitter, NfcPaymentReader } from '@furlpay/nfc';
// See types and tests for usage details.
```
