# FurlPay Android baseline profile — STARTUP SEED
#
# WHAT THIS IS
# Rules describing the classes and methods on the cold-start path. ART compiles
# them ahead of time at install, so the first run of the app does not pay the
# interpreter for them. AGP picks this file up from app/src/main/baseline-prof.txt
# (put there by plugins/withAndroidPerformance.js) and compiles it into
# assets/dexopt/baseline.prof.
#
# WHAT THIS IS NOT
# It is NOT a measured profile. A measured profile is produced by running the
# real app through real journeys under Macrobenchmark and recording which
# methods actually executed; it is strictly better than this file, because it
# captures the exact methods and their hot/startup flags rather than a
# hand-reasoned superset. See README.md in this directory for the exact
# commands. THIS FILE IS THE FLOOR, NOT THE CEILING — replace it with generated
# output when a device is available.
#
# SYNTAX (profgen human-readable format)
#   L<class>;                     include the class
#   H  hot         — called often
#   S  startup     — called during startup
#   P  post-startup— called shortly after startup
#   `**` matches any characters including `/`; `*` stops at a package boundary.
#
# A rule that matches nothing is silently ignored, so an over-broad file costs
# profile size, not correctness. Rules are ordered by when they run.
